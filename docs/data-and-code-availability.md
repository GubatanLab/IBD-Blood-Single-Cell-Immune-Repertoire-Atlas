# Data and code availability

Sequencing datasets will be deposited in the NIH National Center for Biotechnology Information Gene Expression Omnibus (NCBI GEO) at the time of publication. De-identified linked clinical metadata will be shared subject to institutional review board approvals, consent, and applicable data-use restrictions.

Analysis code, immuneML specifications, figure workflows, and non-sensitive processed outputs are publicly available at [GubatanLab/IBD-Blood-Single-Cell-Immune-Repertoire-Atlas](https://github.com/GubatanLab/IBD-Blood-Single-Cell-Immune-Repertoire-Atlas). Version 1.0.0 is archived in Zenodo under DOI [10.5281/zenodo.22866361](https://doi.org/10.5281/zenodo.22866361).

The primary cohort expression matrices, cell-level receptor sequences, participant-level clinical records, individual model predictions, and trained model artifacts are not included in this public code repository. External-validation datasets are available under GSE261334, GSE125527, and GSE301689, as described in the manuscript.

This statement accompanies the public software release and supersedes the EGA destination and pending code-release/DOI wording in the unchanged, dated manuscript snapshot. It does not assert that the primary sequencing datasets have already been deposited or that the manuscript has been accepted for publication.
