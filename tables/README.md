# Supplementary tables

These seven files are copied without altering the supplied values or workbook formatting. Their current manuscript descriptions are in `Supplementary_table_legends.txt`.

| Table | Contents | Format |
|---|---|---|
| S1 | Clinical and demographic cohort summaries | DOCX |
| S2 | CD versus control Milo neighborhood differential abundance; 62,426 neighborhoods | CSV |
| S3 | UC versus control Milo neighborhood differential abundance; 38,371 neighborhoods | CSV |
| S4 | CD versus UC Milo neighborhood differential abundance; 66,508 neighborhoods | CSV |
| S5 | Historical TCR model screen; 594 model-comparison records | XLSX |
| S6 | Historical BCR model screen; 522 model-comparison records | XLSX |
| S7 | 17 core T-cell and 19 core B-cell transcriptional signatures | XLSX |

S2-S4 contain neighborhood-level statistics, neighborhood-center indices, and cell-type annotations rather than participant-level clinical records or expression profiles. Neighborhood abundance is not interchangeable with whole-state cell frequency.

S5 and S6 document the broader historical model screen. They do not replace the primary nested diagnosis estimates in Figure 7B or the conditional post-selection estimates in Figure 7D,F. Response analyses classify contemporaneous response status rather than pretreatment response prediction.

S7 retains its original internal worksheet labels and source-provenance notes. Its current manuscript designation is Table S7; the current table legend governs its scope. Analysis-specific variants of the core signatures are described separately in STAR Methods.
